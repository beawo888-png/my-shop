# 네이버 검색광고 키워드 분석 (읽기 전용)

판교점·모란본점 검색광고 계정에 넣어 둔 키워드를 모두 읽어, **어떤 키워드가 검색이 잘 되고 돈값을 하는지** 바탕화면 엑셀 한 파일로 정리한다.
광고 설정은 아무것도 바꾸지 않는다(GET 요청만 한다). 자동 조정은 이 분석을 사장님과 확인한 뒤 다음 단계에서 붙인다.

> Pencil(`초안`) 스케치 단계는 해당 없음: 사이트 화면을 바꾸지 않는 사장님 PC 엑셀 보고서다.

- 네이버 공식 검색광고 API(https://naver.github.io/searchad-apidoc/)를 쓴다. 크롬을 조작하지 않아서 로그인이 풀려 멈추는 일이 없다.
- 키: `.smartplace/searchad.json` (지점별 API 키·비밀키·CUSTOMER_ID, 깃에 올라가지 않음)
- 코드: `lib/searchad/client.mjs`(서명·요청), `lib/searchad/keywords.mjs`(수집·판정·후보), `lib/searchad/report.mjs`(엑셀)

## 처음 한 번만 (10분)

1. 지점 계정마다 네이버 검색광고(searchad.naver.com)에 로그인 → **도구 → API 사용 관리** → 라이선스 발급.
   액세스라이선스, 비밀키, CUSTOMER_ID 세 가지가 나온다. 판교점·모란본점 계정이 따로라서 두 번 한다.
2. 사장님 PC에서 `npm run ads:setup` → 지점마다 세 가지를 붙여 넣는다. 바로 연결을 확인하고 캠페인 수를 보여 준다.

## 분석 엑셀 만들기

`npm run ads:keywords` → 바탕화면 `왕징 검색광고 키워드 분석.xlsx` (기간: 어제까지 30일, `-- --days=14`로 바꿈, 한 지점만 `-- --branch=moran`)

| 시트 | 내용 |
| --- | --- |
| 요약 | 지점별 30일 광고비·클릭·평균 클릭당 비용, 판정별 개수, 검색 많이 되는 키워드 TOP 10 |
| 판교/모란 키워드 | 넣어 둔 키워드 전부(광고비 많은 순): 판정, 이유, 집중 메뉴, 월 검색수, 노출·클릭·광고비, 입찰가, 상태 |
| 판교/모란 새 후보 | 아직 안 넣은 연관 검색어 중 그 지점 동네 + 왕징 관련(양꼬치·양다리·회식 등)만. 양다리·양꼬치 먼저, 검색수 많은 순 |
| 판교/모란 광고그룹 | 캠페인·광고그룹별 성과. 플레이스 광고처럼 키워드를 직접 넣지 않는 광고는 여기서 본다 |

## 판정 기준 (그 지점 키워드 평균과 비교)

| 판정 | 기준 |
| --- | --- |
| 잘 되는 키워드 | 30일 클릭 10회 이상 + 클릭당 비용이 평균 이하 |
| 비싼 키워드 | 지점 키워드 광고비의 5% 이상 + 클릭당 비용이 평균의 1.5배 이상 |
| 클릭률 낮음 | 노출 300회 이상인데 클릭률이 평균의 절반 미만 |
| 노출 안 됨 | 30일 노출 0 (입찰가가 낮거나 조건 확인) |
| 꺼져 있음 | 중지된 키워드 |
| 검색 거의 없음 | 네이버 월간 검색수 50 미만 |

- 예약 수는 아직 붙이지 않았다. 네이버 '전환' 추적을 켜 둔 계정이면 성과에 전환 수(ccnt)가 같이 들어온다.
- 월간 검색수는 네이버 키워드 도구 값(PC+모바일)이다. '10 미만'은 0으로 센다.

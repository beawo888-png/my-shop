# 네이버 검색광고 키워드 분석 (읽기 전용)

판교점·모란본점 검색광고 계정에 넣어 둔 키워드를 모두 읽어, **어떤 키워드가 검색이 잘 되고 돈값을 하는지** 바탕화면 엑셀 한 파일로 정리한다.
광고 설정은 아무것도 바꾸지 않는다(GET 요청만 한다). 자동 조정은 이 분석을 사장님과 확인한 뒤 다음 단계에서 붙인다.

> Pencil(`초안`) 스케치 단계는 해당 없음: 사이트 화면을 바꾸지 않는 사장님 PC 엑셀 보고서다.

- 네이버 공식 검색광고 API(https://naver.github.io/searchad-apidoc/)를 쓴다. 크롬을 조작하지 않아서 로그인이 풀려 멈추는 일이 없다.
- 키: `.smartplace/searchad.json` (지점별 API 키·비밀키·CUSTOMER_ID, 깃에 올라가지 않음)
- 코드: `lib/searchad/client.mjs`(서명·요청), `lib/searchad/keywords.mjs`(수집·판정·후보), `lib/searchad/report.mjs`(엑셀)

## 처음 한 번만 (10분)

1. 지점 계정마다 네이버 검색광고(searchad.naver.com)에 로그인 → **도구 → API 사용 관리** → 라이선스 발급.
   액세스라이선스, 비밀키, CUSTOMER_ID 세 가지가 나온다. 판교점·모란본점 계정이 따로라서 두 번 한다.
2. 사장님 PC에서 `npm run ads:setup` → 지점마다 세 가지를 붙여 넣는다. 바로 연결을 확인하고 캠페인 수를 보여 준다.

## 분석 엑셀 만들기

`npm run ads:keywords` → 바탕화면 `왕징 검색광고 키워드 분석.xlsx` (기간: 어제까지 30일, `-- --days=14`로 바꿈, 한 지점만 `-- --branch=moran`)

| 시트 | 내용 |
| --- | --- |
| 요약 | 지점별 30일 광고비·클릭·평균 클릭당 비용, 판정별 개수, 검색 많이 되는 키워드 TOP 10 |
| 판교/모란 키워드 | 넣어 둔 키워드 전부(광고비 많은 순): 판정, 이유, 집중 메뉴, 월 검색수, 노출·클릭·광고비, 입찰가, 상태 |
| 판교/모란 새 후보 | 아직 안 넣은 연관 검색어 중 그 지점 동네 + 왕징 관련(양꼬치·양다리·회식 등)만. 양다리·양꼬치 먼저, 검색수 많은 순 |
| 판교/모란 광고그룹 | 캠페인·광고그룹별 성과. 플레이스 광고처럼 키워드를 직접 넣지 않는 광고는 여기서 본다 |

## 판정 기준 (그 지점 키워드 평균과 비교)

| 판정 | 기준 |
| --- | --- |
| 잘 되는 키워드 | 30일 클릭 10회 이상 + 클릭당 비용이 평균 이하 |
| 비싼 키워드 | 지점 키워드 광고비의 5% 이상 + 클릭당 비용이 평균의 1.5배 이상 |
| 클릭률 낮음 | 노출 300회 이상인데 클릭률이 평균의 절반 미만 |
| 노출 안 됨 | 30일 노출 0 (입찰가가 낮거나 조건 확인) |
| 꺼져 있음 | 중지된 키워드 |
| 검색 거의 없음 | 네이버 월간 검색수 50 미만 |

- 예약 수는 아직 붙이지 않았다. 네이버 '전환' 추적을 켜 둔 계정이면 성과에 전환 수(ccnt)가 같이 들어온다.
- 월간 검색수는 네이버 키워드 도구 값(PC+모바일)이다. '10 미만'은 0으로 센다.

## 라이브애드 기간 점검 (9월처럼 멈춘 날 찾기)

`npm run ads:history` → 바탕화면 `왕징 라이브애드 기간 점검.xlsx` (기본: 8/1부터 어제까지, `-- --since=2026-09-01 --until=2026-09-30`으로 바꿈)

- 라이브애드 캠페인 = 이름에 '프로그램'이 들어간 캠페인. 날짜별 노출·클릭·광고비·평균 순위를 받는다.
- 그날 라이브애드 클릭이 기간 중간값의 50% 미만, 노출이 40% 미만이거나 평균 순위가 2칸 이상 밀리면 '멈춤 의심'.
  (2026-08-14~27 라이브애드가 약해졌을 때 노출은 절반쯤 남았지만 클릭은 약 70% 줄었다.)
- 바탕화면 `판교점 예약고객.xlsx`, `모란점 예약고객.xlsx`의 날짜별 예약(취소 제외)과 나란히 놓고,
  멈춘 날의 예약을 **같은 요일의 정상인 날 평균**과 비교한다(요일마다 손님 수가 달라서).
- 엑셀에 8월 예약이 없으면 먼저 `npm run smartplace:bookings-backfill -- --from=2026-08-01`.
- 삭제된 캠페인은 목록에 없어서 빠진다. 9월에 쓰다가 지운 라이브애드 캠페인이 있으면 그만큼 덜 잡힌다.

## 라이브애드 감시 카톡 알림 (매일 08:20)

어제 라이브애드 캠페인의 클릭·노출·평균 순위를 지난 28일 평소(중간값)와 비교해, 이상하면 카카오톡 '나에게 보내기'로 알린다.
2026-08-14~27 두 주 동안 라이브애드가 약해진 것을 아무도 몰랐고(클릭 약 70% 감소, 사장님 말씀으로 매출 약 1,500만 원 감소), 그 일을 다음 날 아침에 잡으려는 것이다.

```
[왕징 라이브애드] 11/14 확인 필요
⚠️ 판교: 약해짐 의심 3일째 - 클릭 11 (평소 45)
✅ 모란: 정상 (클릭 45, 평소 45)
라이브애드 화면에서 캠페인 상태·잔액·연동을 확인해 주세요.
```

- 약해짐 의심: 클릭이 평소의 50% 미만, 노출이 40% 미만, 또는 평균 순위가 2칸 이상 밀림. 멈춤 의심: 노출 0.
- 정상이면 보내지 않는다. 월요일에만 "이번 주도 정상 감시 중" 한 통(감시가 살아 있다는 확인).
- 점검이 실패해도(키 문제, 네이버 오류) 카톡으로 알린다. 같은 날 같은 알림은 한 번만.
- 라이브애드 캠페인 = 이름에 '프로그램'. 읽기만 하고 절대 바꾸지 않는다.
- 카톡은 블로그 알림과 같은 설정(`.smartplace/kakao.json`, `npm run kakao:setup`)을 쓴다.
- 코드: `lib/searchad/watch.mjs`, `scripts/searchad/livead-watch.mjs`, 기록 `.smartplace/livead-watch.jsonl`, 로그 `.smartplace/livead-watch.log`

| 명령 | 하는 일 |
| --- | --- |
| `npm run ads:watch-test` | 카톡은 안 보내고 지금 상태와 보낼 메시지를 화면에 보여 줌 |
| `npm run ads:watch` | 실제 점검 (이상하면 카톡) |
| `npm run ads:watch -- --always` | 정상이어도 카톡 한 통 (카톡이 오는지 확인용) |
| `npm run ads:watch-schedule` | 작업 스케줄러에 매일 08:20 등록 (`WangjingLiveAdWatch`) |
| `npm run ads:watch-unschedule` | 등록 해제 |

## 키워드 끄기 2주 시험 (되돌릴 수 있음)

광고를 실제로 바꾸는 유일한 명령이다. 세 단계로 나눠 사장님이 엑셀로 확인한 것만 끈다.

| 명령 | 하는 일 |
| --- | --- |
| `npm run ads:pause` | 끌 목록만 만든다(아무것도 안 바꿈) → 바탕화면 `왕징 끌 키워드 확인.xlsx`. 끄고 싶지 않은 줄은 지우고 저장 |
| `npm run ads:pause-apply` | 엑셀에 남은 줄만 끈다(네이버 '사용자 중지'). 3일 지난 목록은 거절 |
| `npm run ads:pause-restore` | 이 프로그램이 끈 키워드를 모두 다시 켠다 |

- 목록: `data/searchad/pause-2026-11-recipe.json` — 판교의 엉뚱한 '경기+단어' 16개(30일 약 1.1만 원)만.
  요리 이름·레시피·나들이 장소 키워드와 지역소상공인광고는 **브랜드 노출 목적**(사장님, 2026-11-16)이라 끄지 않는다.
  노출 1천 번에 59~221원(지역소상공인 544원)으로 메타(3,664~4,881원)보다 훨씬 싸다.
- 라이브애드 캠페인(이름에 '프로그램')은 같은 단어가 있어도 건너뛴다. 이미 꺼져 있던 키워드는 기록하지 않아 되돌릴 때도 켜지 않는다.
- 기록: `.smartplace/paused-keywords.json`, 확인한 목록: `.smartplace/pause-plan.json`
- 2주 뒤 POS 매출을 같은 요일 평소와 비교해 5% 넘게 줄었으면 되돌린다.
- 코드: `lib/searchad/pause.mjs`, `scripts/searchad/pause-keywords.mjs`. 쓰기는 `createClient(keys, { allowWrite: true })`에만 있다.

## 키워드 검색수 전체 (두 지점 고유 키워드 약 10만 개)

`npm run ads:volumes` → 바탕화면 `왕징 키워드 검색수.xlsx` (읽기만 함)

- 두 지점 키워드와 30일 성과를 읽고, 고유 키워드마다 네이버 월간 검색수(PC+모바일)를 붙여 검색 많은 순으로 정리.
- 처음에는 1시간 가까이 걸린다. 받은 검색수는 `.smartplace/keyword-volumes.json`에 쌓여 끊겨도 이어서 받고, 30일 동안은 다시 묻지 않는다.
- 분류: ① 가게 이름 ② 우리 동네 + 메뉴 ③ 우리 동네 ④ 동네 없는 넓은 단어 ⑤ 양고기(동네 없음·다른 동네) ⑥ 요리 이름(동네 없음) ⑦ 다른 동네 ⑧ 기타.
- 시트: 요약(분류별 키워드 수·검색수·지점별 클릭·광고비) · 검색 많은 순(10회 이상) · 우리 동네 키워드.
- 코드: `lib/searchad/volumes.mjs`, `scripts/searchad/keyword-volumes.mjs`

# 네이버 블로그 모임 키워드 글 매일 자동 발행 (저녁)

판교점·모란본점 네이버 블로그에 **매일 저녁 지점마다 2편씩** 모임 키워드 글을 올린다.
- 1편: **18:00**
- 2편: **18:30** (두 편을 몇 초 간격으로 올리면 기계로 쓴 글처럼 보여서 30분을 띄운다)
- 19:10: 예비 실행. 못 올린 글만 올린다.
- 기간: **2026-11-01 ~ 2026-12-31** (원고집 `startDate`·`endDate`)

오전 10시 메뉴 소개 글(`naver-blog-automation.md`)은 그대로 나간다. 그래서 블로그마다 하루 3편이 올라간다.

> Pencil(`초안`) 스케치 단계는 해당 없음: 사이트 화면을 바꾸지 않는 사장님 PC 자동화다.

## 주제(테마)

| 테마 | 대표 검색어 | 나가는 기간 |
| --- | --- | --- |
| 연말모임·송년회 | 판교 연말모임, 모란 송년회 장소 | 내내 (다른 테마보다 2배 자주 나간다) |
| 회식 | 판교역 회식 장소, 모란 부서 회식 | 내내 |
| 단체모임 | 판교 단체모임, 모란역 단체석 맛집 | 내내 |
| 청첩장모임 | 판교 청첩장 모임, 모란 청모 장소 | 내내 |
| 가족모임 | 모란 가족외식, 판교 가족모임 | 내내 |
| 생일·기념일 모임 | 판교 생일 모임, 모란역 생일파티 장소 | 내내 |
| 동창회·동호회 | 모란 동창회, 판교역 동호회 모임 | 내내 |
| 크리스마스 모임 | 판교 크리스마스 모임 | 11/15 ~ 12/25 |
| 신년회 | 모란 신년회 장소 | 12/10 ~ 12/31 |
| 비즈니스 미팅·접대 | 판교 접대 장소 | 내내, **판교점만** |

- 같은 날 올라가는 네 편(두 지점 × 2편)은 모두 다른 테마다.
- 한 블로그 안에서는 제목이 한 번도 겹치지 않는다(검색어 5개 × 제목 꼬리 6개를 돌려 쓴다).
- 글 하나는 띄어쓰기를 포함해 **약 1,800~2,250자**다.

## 글은 이렇게 만들어진다

원고집: `content/blog/gathering-posts.json`

인사 → 테마 도입 → **실제 사진 1** → 왜 왕징인지 → **AI 연출 사진 + "※ 매장 분위기를 표현한 AI 연출 이미지입니다."**
→ 지점 공간 소개(판교·모란 실제 인테리어) → **실제 사진 2** → 인원별 메뉴 고르기 → **메뉴 사진**
→ 모임 팁 → 예약 팁 → 자주 묻는 질문 → 지점 안내(주소·오시는 길·주차·단체석·전화)
→ ⏰ 양다리구이 1시간 전 예약 안내 → 📅 네이버 예약 · 📍 네이버 지도 링크 → **외관 사진** → 맺음말

- 가격은 넣지 않는다(지점마다 다름). 원고에 가격이 들어가면 점검에서 걸린다.
- 매장에 없는 시설(룸 등)이나 할인 이야기는 쓰지 않는다.
- 태그: 지점 이름을 붙인 테마 태그(판교연말모임 등) + 테마 태그 + 지점 태그 + 공통 태그, 30개 이하.

## 사진 폴더 (사장님 PC)

프로젝트 폴더 안에 지점별 사진 폴더를 둔다. 깃에는 올라가지 않는다.

```
C:\vibecoding\my-shop\판교블로그이미지\        ← 판교점 실제 사진 (jpg·png·webp)
C:\vibecoding\my-shop\판교블로그이미지\AI연출\연말모임 등 테마별 폴더\
C:\vibecoding\my-shop\모란블로그이미지\        ← 모란본점 실제 사진
C:\vibecoding\my-shop\모란블로그이미지\AI연출\...
```

- 프로젝트 폴더 바로 바깥(`C:\vibecoding\판교블로그이미지`)에 있어도 찾는다.
  다른 곳에 있으면 `.smartplace/config.json`에 경로를 넣는다:
  ```json
  { "blogPhotoDirs": { "pangyo": "D:\\사진\\판교블로그이미지", "moran": "D:\\사진\\모란블로그이미지" } }
  ```
- 실제 사진은 글마다 2장씩, 폴더 안 순서대로 돌아가며 쓴다. 사진이 많을수록 같은 사진이 덜 반복된다.
- 폴더가 비어 있으면 홈페이지 지점 내부 사진으로 대신하고 경고를 보여 준다.
- 모란본점 글에는 모란 폴더 사진만, 판교점 글에는 판교 폴더 사진만 들어간다.

## AI 연출 사진 (단체 모임 장면)

우리 매장 내부 사진을 참고로 넣고, **같은 매장에서 손님들이 모임을 하는 장면**을 만든다.
판교점은 검은 대리석 무늬 테이블·소파석·빨간 등불, 모란본점은 나무 테이블·은색 배출관·빨간 등불이 그대로 나오도록 지시한다.

1. OpenAI API 키를 넣는다(한 번만, 비용은 OpenAI 계정에서 나간다):
   ```powershell
   setx OPENAI_API_KEY "sk-..."
   ```
   창을 닫고 새로 연다. 키는 깃이나 설정 파일에 저장하지 않는다.
2. (선택) 매장 내부가 잘 보이는 사진을 `판교블로그이미지\AI연출\참고\`, `모란블로그이미지\AI연출\참고\`에 2~3장 넣어 두면 더 비슷하게 나온다.
3. 만들기:
   ```powershell
   npm run moim:ai-photos                                  # 두 지점 × 모든 테마 × 2장
   npm run moim:ai-photos -- --branch=moran --theme=wedding --count=3
   npm run moim:ai-photos -- --dry-run                     # 만들지 않고 지시문만 보기
   ```
4. **폴더를 열어 한 장씩 본다.** 손가락·얼굴·글자가 이상하거나 매장과 다른 사진은 지운다. 남은 사진만 글에 들어간다.

- AI 사진 바로 아래에는 항상 **"※ 매장 분위기를 표현한 AI 연출 이미지입니다."**가 붙는다.
  실제 손님 사진처럼 보이게 하면 광고 표시 규정이나 손님 불만 문제가 생길 수 있어서 빼지 않는다.
- 테마 폴더에 사진이 없으면 `AI연출\` 바로 안에 있는 사진(공통)을 쓰고, 그것도 없으면 AI 사진 없이 올린다.
- 모델을 바꾸려면 `config.json`에 `"aiImageModel": "모델이름"`을 넣는다(기본 `gpt-image-1`).

## 처음 한 번만 하는 설정

메뉴 글 자동화(`npm run blog:setup`)로 로그인을 해 뒀다면 그대로 쓴다.

```powershell
git pull
npm install
npm run moim:check      # 원고 점검 + 사진 폴더 확인 + 앞으로 2주 제목
npm run moim:test       # 최종 '발행' 직전까지 채우고 멈춤 (판교 1편 → 판교 2편 → 모란 1편 → 모란 2편)
npm run moim:schedule   # 작업 스케줄러에 WangjingNaverBlogGathering 등록 (18:00 · 18:30 · 19:10)
```

지우려면 `npm run moim:unschedule`.

## 자주 쓰는 명령

| 명령 | 하는 일 |
| --- | --- |
| `npm run moim:preview` | 오늘 올라갈 네 편을 터미널에 보여 준다 |
| `npm run moim:preview -- --date=2026-12-20` | 그날 글 미리 보기 |
| `npm run moim:check` | 원고 점검, 사진 폴더 상태, 앞으로 2주 제목 |
| `npm run moim:post -- --branch=moran --slot=2` | 모란본점 2편만 지금 발행 |
| `npm run moim:post -- --force` | 오늘 이미 올렸어도 다시 발행 |

- 기록: `.smartplace/blog-log.jsonl`(`"kind": "gathering"`), 실행 로그 `.smartplace/blog-moim-task.log`,
  화면 `.smartplace/screenshots/blog-moim-*.png`
- 모임 글만 다른 카테고리로 올리려면 `config.json`에 `"blogGatheringCategory": "카테고리이름"`.

## 알고 쓸 것

- 블로그마다 하루 3편(메뉴 1 + 모임 2)이 자동으로 올라간다. 네이버가 같은 틀의 글이 많다고 보면 노출이 줄 수 있다.
  조회수가 떨어지면 모임 글을 하루 1편(`--slot=1`만 실행)으로 줄이는 것을 먼저 해 본다.
- 원고 문장(예: 케이크 지참, 법인카드 결제, 조용한 자리 배정)이 매장 운영과 다르면 `gathering-posts.json`에서 고친다.
- 18:00에 PC가 켜져 있고 윈도우에 로그인돼 있어야 한다.
- 2027년에도 이어 가려면 `endDate`를 늘리고, 연말 테마 대신 새 테마를 추가한다.

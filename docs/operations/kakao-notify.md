# 카카오톡으로 블로그 발행 결과 받기

매일 10시 반 블로그 발행(`docs/operations/naver-blog-automation.md`)이 끝나면, 사장님 카카오톡 **나와의 채팅**으로 결과를 한 통 보낸다.

> Pencil(`초안`) 스케치 단계는 해당 없음: 사이트 화면을 바꾸지 않는 사장님 PC 알림이다.

```
[왕징 블로그] 11/9 발행 3편 성공, 1편 실패
✅ 판교 1 어향육사
✅ 모란 1 물만두
❌ 판교 2 오이무침 - 로그인 풀림
⚠️ 모란 2 가지볶음밥 - 링크 확인 필요
자세한 내용은 PC 알림 창을 봐 주세요.
```

- 카카오 공식 API(카카오톡 메시지 '나에게 보내기')를 쓴다. 다른 사람에게는 가지 않는다.
- 이미 다 올린 날 11:10 실행처럼 올릴 글이 없으면 보내지 않는다. 시험 실행(`blog:test`)도 보내지 않는다.
- 알림이 실패해도 블로그 발행은 그대로 된다.
- 키와 토큰은 사장님 PC의 `.smartplace/kakao.json`에만 있다(깃에 올라가지 않음).
- 코드: `lib/notify/kakao.mjs`(보내기·토큰 갱신), `lib/blog/report.mjs`(메시지 만들기), `scripts/notify/kakao-setup.mjs`

## 처음 한 번만 하는 설정

### 1. 카카오 개발자 앱 만들기 (10분)

카카오 개발자 사이트는 화면이 자주 바뀌어서 메뉴 이름이 조금 다를 수 있다.

1. **developers.kakao.com**에 사장님 카카오 계정으로 로그인한다.
2. **내 애플리케이션 → 애플리케이션 추가하기**: 앱 이름은 `왕징 알림`, 회사명은 가게 이름으로 쓴다.
3. 만든 앱의 **앱 키**에서 **REST API 키**를 복사해 둔다.
4. **카카오 로그인**을 **활성화(ON)**하고, **Redirect URI**에 `http://localhost:5174/kakao`를 등록한다.
5. **카카오 로그인 → 동의항목**에서 **카카오톡 메시지 전송(talk_message)**을 **이용 중 동의**(또는 선택 동의)로 켠다.
6. **플랫폼 → Web**에 사이트 도메인 `https://blog.naver.com`을 등록한다. 메시지의 '블로그 보기' 버튼이 이 주소로 열린다.
7. **보안**에서 **Client Secret**을 켰다면 그 값도 복사해 둔다. 안 켰으면 넘어간다.

### 2. PC에서 연결

```powershell
cd C:\vibecoding\my-shop
git pull
npm run kakao:setup
```

1. REST API 키를 붙여 넣고 엔터, 클라이언트 시크릿은 없으면 그냥 엔터를 누른다.
2. 브라우저에 카카오 로그인 화면이 뜨면 로그인하고 **카카오톡 메시지 전송**에 동의한다.
3. "카카오톡 알림 연결 완료!" 화면이 뜨고, 카카오톡 나와의 채팅에 시험 메시지가 온다.

언제든 `npm run kakao:test`로 시험 메시지를 다시 보낼 수 있다.

## 알아 둘 것

- 토큰은 매일 쓰면 자동으로 이어진다. PC를 두 달 넘게 안 켜서 끊기면 `npm run kakao:setup`을 다시 한다.
- 알림이 안 오면 `.smartplace\blog-task.log` 끝에 `카카오톡 알림을 보내지 못했습니다`와 이유가 남는다.
- 카카오톡 메시지 한 통은 200자까지라 결과는 짧게 줄여 보낸다. 자세한 오류는 PC 알림 창과 로그에 있다.

# 상단 네이버 예약 지점 선택 디자인

## 목표

- 우측 상단 `네이버 예약` 버튼에서 모란본점과 판교점 예약을 선택할 수 있게 한다.
- 기존 왕징의 검정·크림·적색 색상과 헤더 크기를 유지한다.
- 본문과 다른 예약 CTA의 기존 판교점 연결은 이번 작업에서 변경하지 않는다.

## Pencil 기준

- Pencil 파일: `C:\vibecoding\my-shop\초안`
- 상세 스케치: `상단 예약 지점 선택 상세 스케치` (`VJ70t`)
- 데스크톱 헤더 메타데이터에 드롭다운과 닫기 동작을 기록했다.
- 모바일 헤더 메타데이터에 두 지점 예약 링크를 기록했다.

## 예약 데이터

- 모란본점: `https://booking.naver.com/booking/6/bizes/721603`
- 판교점: `https://booking.naver.com/booking/6/bizes/970819`
- 두 링크는 한 데이터 배열에서 관리하여 데스크톱과 모바일이 같은 값을 사용한다.

## 데스크톱 동작

- 기존 `네이버 예약` 자리에 버튼을 유지하고 아래 화살표를 표시한다.
- 버튼을 누르면 바로 아래에 `모란본점 예약`, `판교점 예약` 순서로 메뉴가 열린다.
- 링크는 새 탭에서 열고 `rel="noreferrer"`를 사용한다.
- 버튼을 다시 누르거나 바깥 영역을 클릭하거나 `Escape` 키를 누르면 메뉴가 닫힌다.
- 버튼은 `aria-expanded`와 `aria-controls`로 열린 상태와 대상 패널을 알린다.

## 모바일 동작

- 햄버거 메뉴 안의 기존 단일 예약 링크를 두 지점 링크로 교체한다.
- `모란본점 예약`을 먼저, `판교점 예약`을 다음에 배치한다.
- 지점 링크를 누르면 모바일 메뉴를 닫고 예약 페이지를 새 탭에서 연다.

## 시각 규칙

- 예약 트리거는 기존 적색 버튼 스타일을 유지한다.
- 드롭다운은 크림색 배경, 짙은 글자, 얇은 베이지 테두리를 사용한다.
- 각 메뉴 항목은 최소 높이 48px, 글자 크기 16px 이상을 유지한다.
- 드롭다운은 헤더와 Hero보다 앞에 보이도록 충분한 쌓임 순서를 갖는다.

## 구현 범위

- `lib/site-content.ts`에 두 지점 예약 링크 데이터를 추가한다.
- `components/home/site-header.tsx`에 버튼 상태, 바깥 클릭, Escape 닫기 동작을 추가한다.
- `app/globals.css`에 데스크톱 드롭다운과 모바일 예약 링크 스타일을 추가한다.
- 기존 Hero, 단체 모임, 예약 배너, 푸터, 하단 고정 예약 버튼의 링크는 유지한다.

## 검증

- 테스트가 두 예약 URL과 모란본점 우선 순서를 확인한다.
- 테스트가 버튼의 접근성 상태와 두 모바일 링크를 확인한다.
- 전체 테스트, ESLint, Next.js 프로덕션 빌드를 실행한다.
- 배포 후 공식 도메인에서 두 예약 링크가 포함된 HTML과 배포 상태를 확인한다.

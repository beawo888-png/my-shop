# 왕징양다리양꼬치 로고 교체 설계

## 목표

홈페이지 헤더와 푸터의 기존 한자 원형 로고 및 `판교왕징` 워드마크를 사용자가 제공한 `왕징양다리양꼬치` 가로형 로고 이미지로 교체한다. 헤더와 푸터의 기존 배경색, 내비게이션 구조, 예약 동선은 유지한다.

## 범위

- 헤더의 한자 원형 로고와 `판교왕징` 텍스트를 제거하고 제공 로고 이미지를 홈 링크로 표시한다.
- 푸터의 한자 및 상호명 조합을 제거하고 같은 로고 이미지를 표시한다.
- 푸터 저작권 문구를 `© 2026 왕징양다리양꼬치. All rights reserved.`로 변경한다.
- 본문에서 지점이나 브랜드를 설명하기 위해 사용한 `판교`, `왕징` 등의 일반 콘텐츠는 변경하지 않는다.
- 데스크톱과 모바일에서 로고 비율을 보존하고 기존 헤더 높이와 푸터 그리드 안에 맞춘다.

## 시각 처리

원본 JPG의 글자와 심볼을 그대로 사용한다. 검은 이미지 배경은 CSS의 `mix-blend-mode: screen`으로 기존의 어두운 헤더 및 푸터 배경에 합성한다. 불투명 JPG가 반투명 헤더 뒤의 화면을 가리는 현상을 막기 위해 헤더는 기존 색상과 동일한 `#17110f`(`--ink`)를 불투명하게 사용한다. 이 방식은 로고 글자 모양을 다시 만들지 않으면서 검은 사각형이 드러나지 않게 하고 기존 배경색을 유지한다.

Pencil 원본의 데스크톱·모바일 헤더와 푸터 프레임 이름에 제공 로고 적용 상태를 명시해 화면 설계의 기준을 먼저 갱신한다. 앱 구현은 그 갱신된 방향을 따른다.

## 구현 구조

- 제공 이미지를 `public/images/wangjing/` 아래의 웹 자산으로 복사한다.
- Next.js `Image` 컴포넌트를 사용해 헤더와 푸터에서 같은 자산을 렌더링한다.
- 헤더 로고는 기존 홈 링크와 접근 가능한 이름을 유지한다.
- 푸터 로고에는 상호를 설명하는 대체 텍스트를 제공한다.
- 공통 로고 스타일과 헤더·푸터별 반응형 크기를 CSS에 정의한다.

## 반응형 동작

- 데스크톱 헤더에서는 내비게이션과 예약 버튼을 침범하지 않는 범위에서 로고를 표시한다.
- 태블릿과 모바일에서는 원본 비율을 유지한 채 로고 폭을 줄이고, 메뉴 버튼 및 헤더 높이를 유지한다.
- 푸터에서는 현재 그리드 흐름을 유지하며 작은 화면에서 로고가 컨테이너 폭을 넘지 않도록 한다.

## 오류 및 접근성

- 로고가 로드되지 않아도 링크의 접근 가능한 이름으로 브랜드와 홈 이동 목적을 알 수 있게 한다.
- 장식용 텍스트를 별도로 중복 렌더링하지 않아 스크린 리더가 상호명을 반복해서 읽지 않게 한다.
- 이미지 크기를 명시해 로딩 중 레이아웃 이동을 방지한다.

## 테스트와 완료 기준

- 구조 테스트에서 헤더와 푸터가 새 로고 자산을 사용하고 기존 한자/`판교왕징` 워드마크를 렌더링하지 않는지 확인한다.
- 저작권 상호가 `왕징양다리양꼬치`로 변경됐는지 확인한다.
- 기존 테스트, ESLint, 프로덕션 빌드를 실행한다.
- 데스크톱 및 모바일 화면에서 로고 가독성, 기존 배경색 유지, 내비게이션과의 겹침 여부를 시각적으로 확인한다.
- `main` 브랜치에 커밋·푸시한 뒤 기존 Vercel 프로젝트 `my-shop-39ab`의 자동 배포 완료와 배포 도메인 응답을 확인한다. 새 Vercel 프로젝트는 생성하지 않는다.

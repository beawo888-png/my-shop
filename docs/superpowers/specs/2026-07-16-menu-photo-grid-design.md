# 판교점 전체 메뉴 사진형 3열 디자인

## 목표

- 판교점 전체 메뉴를 사진 중심 카드로 바꾸고 데스크톱에서 3열로 표시한다.
- 태블릿은 2열, 모바일은 1열로 줄여 메뉴명과 가격을 읽기 쉽게 유지한다.
- 점심특선 5개는 분류와 메뉴 데이터에서 모두 제외하고 총 47개만 게시한다.
- 본문, 설명, 분류 글씨는 16px보다 작게 만들지 않는다.

## 메뉴 범위

- 양고기·꼬치 7개
- 중국요리·탕 16개
- 식사·면·디저트 6개
- 주류·하이볼 18개
- 점심특선 분류와 5개 메뉴는 화면, 데이터, 구조화 데이터에서 모두 제거한다.

## 사진 출처와 우선순위

1. 음식은 사용자가 제공한 `왕징메뉴사진.zip`의 매장 보유 사진을 우선 사용한다.
2. ZIP에 정확한 메뉴 사진이 없으면 판교왕징 네이버 플레이스에서 매장이 등록한 메뉴 사진을 사용한다.
3. 주류 18개는 판교왕징 네이버 플레이스의 매장 등록 주류 사진 6장을 종류별로 반복 사용한다.
4. 방문자·리뷰·블로그 사진과 AI 생성 사진은 사용하지 않는다.
5. 외부 주소로 직접 표시하지 않고 프로젝트 자산으로 저장해 원본 출처의 삭제나 주소 변경에 영향을 받지 않게 한다.

## 사진 연결 규칙

- `양다리.jpg`는 90,000원과 80,000원 양다리 메뉴에 함께 사용한다.
- `양갈비.jpg`, `양갈비살.jpg`, `쇼룽샤.jpg`, `계란볶음.jpg`는 각각 고급양갈비, 양갈비살꼬치, 소룽샤, 계란볶음밥에 연결한다.
- 중국술 9개는 네이버의 중국술·술잔 사진 3장을, 맥주 3개는 맥주 사진 2장을 번갈아 사용한다.
- 하이볼 6개는 네이버 메뉴에 등록된 커티삭하이볼 사진을 공통 대표 사진으로 사용한다.
- ZIP에서 현재 47개 메뉴와 연결되지 않는 조합 사진과 점심특선 사진은 게시하지 않는다.

## 카드와 반응형 화면

- 데스크톱 1200px 이상은 3열, 768~1199px는 2열, 767px 이하는 1열이다.
- 카드 순서는 대표 사진, 메뉴명, 짧은 설명, 가격이며 기존 왕징의 크림·검정·금색·붉은색을 유지한다.
- 음식 사진은 카드 영역을 자연스럽게 채우고, 주류 사진은 병과 잔이 잘리지 않도록 전체 모습을 보여준다.
- 메뉴명은 데스크톱 22px 이상, 모바일 18px 이상, 가격은 18px 이상, 설명은 16px 이상이다.
- 분류 바로가기는 네 분류만 표시하고 각 분류의 개수를 함께 보여준다.

## 데이터와 구성 요소

- `lib/menu-content.ts`에서 점심특선 그룹을 제거하고 각 메뉴에 `imageSrc`, `imageAlt`, `imageFit`을 둔다.
- 메뉴 카드는 하나의 재사용 가능한 구성 요소로 분리해 3열·2열·1열에서 같은 정보를 렌더링한다.
- 모든 사진은 `public/images/wangjing/menu/` 아래에서 영문 파일명으로 관리한다.
- 첫 화면 밖의 사진은 지연 로딩하고, 반응형 이미지 크기를 지정해 모바일 다운로드 용량을 줄인다.

## 오류 처리와 접근성

- 모든 메뉴에 이미지 경로와 구체적인 한국어 대체 설명이 있어야 한다.
- 파일이 없거나 읽히지 않으면 해당 분류의 매장 등록 대표 사진을 표시해 깨진 이미지를 노출하지 않는다.
- 주류 사진의 상품 라벨을 인위적으로 수정하거나 다른 상품처럼 합성하지 않는다.
- 사진 출처나 AI 관련 문구는 고객 화면에 표시하지 않는다.

## 검증 기준

- 메뉴 총합이 47개이고 점심특선 문자열과 항목이 남아 있지 않은지 자동 검사한다.
- 47개 모두 이미지 경로와 대체 설명이 있으며 실제 파일이 존재하는지 검사한다.
- 데스크톱 3열, 태블릿 2열, 모바일 1열에서 겹침·잘림·가로 스크롤이 없는지 확인한다.
- 음식은 보기 좋은 채움, 주류는 전체 표시 규칙이 적용되는지 확인한다.
- ESLint와 프로덕션 빌드를 통과하고 메뉴 구조화 데이터도 47개 범위와 일치시킨다.

## 범위 제외

- 관리자 편집 화면, 예약 기능, 가격 변경 기능은 이번 작업에서 수정하지 않는다.
- 점심특선 사진과 영상 3개는 이번 메뉴 사진 작업에 사용하지 않는다.

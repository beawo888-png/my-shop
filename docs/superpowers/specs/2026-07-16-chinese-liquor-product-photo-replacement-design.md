# 중국 주류 제품 사진 교체 디자인

## 1. 목표

메뉴 페이지의 중국술 9개 항목에 반복 사용 중인 연출 사진 3장을 제거하고, 각 메뉴와 일치하는 실제 제품 병 사진을 적용한다. 고객이 메뉴명과 병 모양을 바로 연결할 수 있게 하며, 기존 메뉴 카드의 정돈된 레이아웃은 유지한다.

## 2. 교체 범위

다음 9개 메뉴에 각각 별도의 제품 이미지를 연결한다.

1. 연태구냥 500ml 34도
2. 연태구냥 250ml 34도
3. 연태구냥 125ml 34도
4. 설원 450ml 30도
5. 설원 250ml 30도
6. 공부가주 500ml 33도
7. 노주탄 500ml 33도
8. 이과두주 125ml 56도
9. 컵술 고량주 100ml 38도

칭다오·하얼빈·타이거 맥주와 하이볼 이미지는 이번 작업에서 변경하지 않는다. 메뉴명, 가격, 설명, 메뉴 순서와 카드 레이아웃도 변경하지 않는다.

## 3. 이미지 선정 원칙

- 제조사 또는 브랜드 공식 채널의 제품 사진을 가장 먼저 사용한다.
- 공식 사진을 구할 수 없으면 제품명, 용량, 도수가 메뉴와 일치하는 공식 판매처의 상품 사진을 사용한다.
- 정면에서 병 전체가 보이고 흰색 또는 밝고 단순한 배경인 사진을 우선한다.
- 메뉴에 표시된 용량의 사진을 우선하며, 다른 용량이나 다른 패키지의 이미지를 대신 사용하지 않는다.
- 상표, 라벨, 병 모양을 수정하거나 AI로 다시 생성하지 않는다.
- 워터마크, 판매가, 할인 배지, 쇼핑몰 UI가 합성된 이미지는 사용하지 않는다.

## 4. 파일과 데이터 연결

제품 이미지는 `public/images/wangjing/menu/`에 로컬 파일로 저장한다. 파일명은 제품과 용량을 식별할 수 있는 영문 소문자 케밥 표기법을 사용한다.

예시:

- `yantai-guniang-500ml.jpg`
- `seolwon-450ml.jpg`
- `gongbu-gaju-500ml.jpg`

`lib/menu-content.ts`에서 중국술 9개 항목을 각 제품 파일에 일대일로 연결한다. 기존 카드의 `contain` 맞춤 방식을 유지해 병과 라벨이 잘리지 않게 표시한다.

## 5. 실패 처리

이미지 로드에 실패하면 기존 중국술 공통 대체 이미지인 `chinese-liquor-toast.jpg`를 표시한다. 정상 상태에서는 기존 `chinese-liquor-toast.jpg`, `chinese-liquor-pour-dark.jpg`, `chinese-liquor-pour-clear.jpg`를 중국술 메뉴 카드의 기본 이미지로 사용하지 않는다.

## 6. 품질과 접근성

- 각 이미지의 대체 텍스트는 메뉴명을 기준으로 생성하는 기존 동작을 유지한다.
- 병 전체가 카드 안에 들어오고 라벨을 알아볼 수 있는 해상도를 확보한다.
- 지나치게 큰 원본은 웹 표시 품질을 해치지 않는 범위에서 최적화한다.
- 모바일, 태블릿, 데스크톱에서 이미지 비율과 여백이 일관되어야 한다.

## 7. 검증 기준

- 중국술 9개가 서로 다른 제품 이미지 파일을 참조한다.
- 각 이미지의 제품명, 용량, 도수가 메뉴 데이터와 일치한다.
- 중국술 카드 모두 `contain` 방식으로 표시된다.
- 맥주, 하이볼, 음식 메뉴 이미지는 변경되지 않는다.
- 이미지 파일 누락 시 공통 대체 이미지가 정상적으로 표시된다.
- 기존 메뉴 사진 및 구조 테스트와 전체 프로젝트 검증이 통과한다.

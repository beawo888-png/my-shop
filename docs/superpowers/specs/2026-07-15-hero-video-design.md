# 상단 대표 영역 홍보 영상 디자인

## 목표

홈페이지 최상단의 양꼬치 대표 이미지를 사용자가 제공한 `양다리 홍보 영상.mp4`로 교체한다. 기존 왕징 색상, 문구, 버튼, 영역 크기와 전환 동선을 유지하면서 방문 즉시 매장의 불향과 조리 장면을 전달한다.

## 승인된 방식

- 영상 파일은 프로젝트의 정적 자산으로 포함한다.
- 영상은 음소거 상태로 자동 재생하고 무한 반복한다.
- 모바일에서는 전체 화면 플레이어로 전환하지 않고 페이지 안에서 재생한다.
- 재생 컨트롤은 표시하지 않는다.
- 영상은 기존 대표 이미지와 같은 영역을 채우며 중앙 기준으로 잘린다.

## 화면 구성

- `HeroSection`의 배경 `Image`만 배경 `video` 요소로 교체한다.
- 제목, 설명, 네이버 예약 버튼, 단체 모임 버튼과 신뢰 정보 영역은 변경하지 않는다.
- 기존 데스크톱·모바일 어두운 오버레이를 유지해 본문과 버튼의 대비를 보호한다.
- 영상 로딩 전과 재생 불가 상황에는 기존 `/images/wangjing/hero-skewers.png`를 포스터로 표시한다.
- 모바일은 기존 시각 초점과 가까운 위치를 유지하도록 영상의 가로 위치를 조정한다.

## 접근성과 성능

- 장식 목적의 배경 영상이므로 음성 정보에 의존하지 않고 접근성 트리에서 숨긴다.
- `autoplay`, `muted`, `loop`, `playsInline`을 함께 사용한다.
- 초기 문서 로딩을 방해하지 않도록 영상 메타데이터만 우선 읽고 포스터를 즉시 표시한다.
- 사용자가 동작 최소화를 설정한 경우 영상을 숨기고 포스터 이미지만 표시한다.
- 원본 약 5MB MP4를 사용하며 추가 외부 영상 서비스는 도입하지 않는다.

## 오류 처리

- 자동 재생이 브라우저 정책이나 네트워크 상태로 막혀도 포스터가 남아 빈 배경이 나타나지 않는다.
- 영상 파일 형식을 지원하지 않는 브라우저에서는 `video` 내부 대체 문구 대신 포스터 화면을 유지한다.
- 영상은 클릭, 예약 버튼, 페이지 내 링크의 포인터 입력을 가로채지 않는다.

## 검증

- 구조 테스트에서 영상 경로와 자동 재생 관련 속성을 확인한다.
- 동작 최소화 스타일에서 영상과 포스터 표시 조건을 확인한다.
- 전체 테스트, ESLint, 프로덕션 빌드를 실행한다.
- 데스크톱과 모바일에서 영상 채움, 오버레이 가독성, 버튼 클릭을 직접 확인한다.
- 배포 후 공식 도메인에서 영상 응답과 대표 영역 표시를 확인한다.

## Pencil 스케치

- `C:\vibecoding\my-shop\초안`의 `desktop-hero`와 `mobile-hero`를 영상 배경 스케치로 갱신했다.
- Pencil은 MP4 재생을 지원하지 않아 기존 대표 이미지를 정적 포스터로 사용했다.
- 두 프레임의 메타데이터에 원본 영상명, 자동 재생, 음소거, 반복, 인라인 재생과 포스터 조건을 기록했다.
- 데스크톱과 모바일 모두 Pencil 레이아웃 검사에서 문제가 없음을 확인했다.

# 리뷰 플랫폼 색상 및 카카오 리뷰 링크 복원 설계

## 목표

`/reviews`의 네이버 플레이스, 카카오맵, 구글 리뷰 버튼을 이전에 승인된 플랫폼 대표색으로 복원하고, 모란본점과 판교점의 카카오맵 버튼이 각 지점의 리뷰 화면을 직접 열도록 수정한다.

## 원인과 복원 원칙

- 과거 구현 커밋 `dd34680`에는 플랫폼별 클래스와 색상 규칙이 존재한다.
- 현재 작업 파일에서는 세 링크가 공통 `review-location-card__button` 클래스만 사용해 회색 배경으로 표시된다.
- 기존 작업 중인 다른 화면과 스타일은 건드리지 않고, 사라진 플랫폼별 클래스와 색상 규칙만 최소 범위로 복원한다.

## 색상 규칙

- 네이버 플레이스: `#03c75a` 배경, `#02ad4f` 테두리, 흰색 글자
- 카카오맵: `#fee500` 배경, `#e4ce00` 테두리, `#191919` 글자
- 구글: `#4285f4` 배경, `#2f6fd8` 테두리, 흰색 글자
- 기존 버튼 크기, 10px 모서리, 호버·포커스 동작, PC 3열 및 모바일 1열 배치를 유지한다.

## 링크 규칙

- 모란본점 카카오맵 리뷰: `https://place.map.kakao.com/1387600612#review`
- 판교점 카카오맵 리뷰: `https://place.map.kakao.com/1537703881#review`
- 네이버와 구글 리뷰 URL, 버튼 순서, 새 탭 열기와 접근성 이름은 변경하지 않는다.

## 검증

- 먼저 현재 구현에서 실패하는 회귀 테스트를 작성해 플랫폼별 클래스, 정확한 색상, 두 카카오 URL을 검사한다.
- 최소 구현 후 해당 테스트와 전체 테스트를 실행한다.
- 린트와 프로덕션 빌드를 실행한다.
- 가능하면 로컬 `/reviews` 화면에서 두 지점의 6개 버튼 색상과 링크 대상을 확인한다.
- 이번 작업에서는 배포하지 않는다.

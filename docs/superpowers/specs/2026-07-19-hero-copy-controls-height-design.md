# 첫 화면 문구·버튼·영상 높이 조정 설계

## 목표

홈페이지 첫 화면의 지점 표현을 판교 단일 지점에서 성남 판교·모란 두 지점으로 확장하고, 영상 위의 불필요한 행동 버튼과 요약 정보 바를 제거한다. 영상은 가로 전체를 채우는 현재 방식을 유지하면서 영역 높이만 약 10% 줄인다.

## 콘텐츠 변경

- 영문 보조 문구를 `WANGJING · PREMIUM CHINESE LAMB DINING`으로 교체한다.
- 큰 제목 `불향으로 완성한 양고기, 중요한 자리를 위한 왕징`은 그대로 유지한다.
- 소개 문구를 `성남 판교·모란에서 만나는 품격있는 양고기전문점. 회식부터 가족모임까지 편안하게 준비 해 드립니다.`로 교체한다.
- 영상 위의 `네이버 예약`과 `단체 모임 안내` 버튼만 삭제한다.
- 헤더 오른쪽의 `네이버 예약` 버튼은 유지한다.
- 영상 하단의 방문자 리뷰, 판교역 4번 출구, 주차·단체석 예약 가능 정보 바를 모두 삭제한다.

## 영상 크기

- 데스크톱 첫 화면 최소 높이를 현재 810px에서 약 10% 줄인 730px로 변경한다.
- 모바일 첫 화면 최소 높이를 현재 820px에서 약 10% 줄인 740px로 변경한다.
- 영상과 포스터의 `object-fit: cover` 및 전체 너비 배치는 유지해 주변 여백이 생기지 않게 한다.
- 삭제되는 버튼과 정보 바에 맞춰 콘텐츠 하단 패딩을 조정해 세로 균형을 유지한다.

## 검증

- 소스 테스트로 새 문구, 유지되는 큰 제목, 삭제되는 두 버튼과 정보 바를 확인한다.
- CSS 테스트로 데스크톱·모바일 높이와 `object-fit: cover` 유지를 확인한다.
- 전체 테스트와 빌드를 실행해 회귀 오류가 없는지 확인한다.

# 지점 주차 안내와 길찾기 버튼 설계

## 목표

홈페이지 지점 카드에서 전화번호 아래에 지점별 주차장 이용방법을 안내하고, 사용자가 네이버 지도 또는 Google 지도로 곧바로 길찾기를 시작할 수 있게 한다. 기존 왕징 홈페이지의 정보 구조와 적색 중심 버튼 디자인은 유지한다.

## 콘텐츠 구조

각 지점 카드의 상세 정보는 다음 순서로 표시한다.

1. 주소
2. 가까운 역
3. 전화번호
4. 주차장 이용방법
5. 네이버 길찾기 버튼
6. 구글 길찾기 버튼

주차 안내는 전화번호와 같은 상세 정보 목록 안에 `주차장 이용방법`이라는 레이블로 추가한다. 길찾기 버튼 두 개는 상세 정보 목록 아래에 세로로 배치한다.

## 지점별 주차 안내

### 모란본점

`가게 앞 주차장 4대 무료이용 또는 근처 모란공영주차장`

### 판교점

`판교 라스트리트(알파리움1타워) 주차장 (3시간 무료주차) 또는 근처 판교 공영주차장`

문구는 사용자가 제공한 표현을 그대로 사용한다.

## 링크 동작

- `네이버 길찾기` 버튼은 기존 `mapUrl`을 사용해 각 지점의 네이버 플레이스를 새 탭에서 연다.
- `구글 길찾기` 버튼은 Google Maps Directions 공식 URL 형식인 `https://www.google.com/maps/dir/?api=1&destination=...`을 사용한다.
- Google 지도 목적지는 각 지점의 전체 주소를 URL 인코딩한 값으로 지정한다.
- Google 계정이 브라우저에 로그인되어 있으면 Google 지도에서 해당 로그인 상태를 그대로 사용한다. 사이트가 Google 로그인 정보나 권한을 직접 다루지는 않는다.
- 모든 외부 링크는 `target="_blank"`와 `rel="noreferrer"`를 사용한다.

## 데이터와 컴포넌트 경계

- `lib/site-content.ts`의 `Location` 타입에 지점별 `parking`과 `googleDirectionsUrl` 필드를 추가한다.
- `LOCATIONS`의 모란본점과 판교점 객체가 각 주차 안내 및 Google 길찾기 URL을 소유한다.
- `components/home/location-card.tsx`는 전달받은 지점 데이터만 렌더링하며 주소로 URL을 즉석 생성하거나 지점별 문구를 직접 포함하지 않는다.
- 기존 `mapUrl`은 상단 지점 캡슐과 네이버 길찾기 버튼에서 계속 공동으로 사용한다.

## 시각 디자인과 반응형 동작

- 주차 안내 행은 기존 주소·가까운 역·전화번호 행과 같은 그리드, 구분선, 적색 레이블 스타일을 사용한다.
- 긴 판교점 안내가 자연스럽게 여러 줄로 흐르도록 값 영역의 폭과 줄바꿈을 유지한다.
- 버튼 영역은 세로 스택으로 구성하고 버튼 사이에 일정한 간격을 둔다.
- `네이버 길찾기`는 기존 적색 기본 버튼을 유지한다.
- `구글 길찾기`는 같은 크기와 터치 영역을 사용하되 테두리형 보조 버튼으로 구분한다.
- 모바일에서도 버튼은 카드 너비 전체를 사용하며 최소 터치 영역 48px을 유지한다.

## 접근성과 오류 처리

- 버튼의 보이는 문구만으로 서비스와 목적을 이해할 수 있게 한다.
- 각 링크의 접근성 이름에는 지점명을 포함해 같은 버튼이 반복되어도 대상을 구분할 수 있게 한다.
- 외부 지도 서비스가 일시적으로 열리지 않아도 주소, 전화번호, 주차 안내는 카드에 계속 표시된다.
- 새 필드가 누락되지 않도록 타입과 콘텐츠 테스트로 두 지점 데이터를 검증한다.

## 테스트와 완료 기준

- 콘텐츠 테스트에서 두 지점의 정확한 주차 문구, 네이버 플레이스 URL, Google Directions URL을 확인한다.
- 구조 테스트에서 주차 안내 행과 두 길찾기 버튼이 데이터 기반으로 렌더링되는지 확인한다.
- 두 외부 링크가 새 탭 보안 속성과 지점별 접근성 이름을 가지는지 확인한다.
- 전체 테스트, ESLint, Next.js 프로덕션 빌드를 실행한다.
- Pencil 스케치에 승인된 정보 행과 버튼 구성을 먼저 반영하고, 데스크톱과 모바일 카드에서 긴 주차 문구의 줄바꿈과 버튼 배치를 시각적으로 검증한다.
- 공개 배포는 사용자가 별도로 요청할 때만 진행한다.

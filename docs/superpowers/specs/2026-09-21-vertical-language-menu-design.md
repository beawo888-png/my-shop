# 세로형 언어 메뉴 디자인

## 목표

홈페이지의 언어 선택 UI를 참고 이미지처럼 한 줄에 하나씩 나열되는 세로형 목록으로 통일한다. PC·태블릿에서는 상단 현재 언어 버튼 아래에 드롭다운으로 표시하고, 모바일에서는 햄버거 메뉴 안에서 같은 순서와 시각 언어를 사용한다.

## 범위

- 지원 언어는 기존 네 개만 유지한다: `한국어`, `English`, `简体中文`, `日本語`.
- 베트남어는 추가하지 않는다.
- 홈페이지 언어 경로 `/`, `/en`, `/zh`, `/ja`와 번역 내용은 변경하지 않는다.
- 메뉴와 리뷰 페이지의 한국어 유지 정책도 변경하지 않는다.

## PC·태블릿 디자인

- 현재 언어와 아래쪽 화살표를 상단 헤더의 간결한 텍스트 버튼으로 표시한다.
- 버튼의 박스형 테두리를 제거하고 기존 헤더 배경색과 자연스럽게 이어지게 한다.
- 버튼을 누르면 바로 아래에 밝은 종이색 패널이 열린다.
- 패널에는 네 언어를 한 줄씩 세로로 나열하고 행 사이 구분선은 사용하지 않는다.
- 현재 언어는 왕징 골드 색상과 굵은 글자로 구분한다.
- 마우스 오버와 키보드 포커스 상태는 기존 왕징 색상 토큰으로 명확히 표시한다.

## 모바일 디자인

- 언어 목록은 햄버거 메뉴 안에 별도의 세로 목록으로 표시한다.
- 네 언어를 PC와 동일한 순서로 한 줄씩 배치한다.
- 각 항목은 손가락으로 누르기 충분한 높이를 유지한다.
- 현재 언어, 호버, 포커스 표시는 PC와 동일한 의미를 갖는다.
- 하단 고정 예약 바와 겹치지 않도록 기존 스크롤 가능한 모바일 메뉴 구조를 유지한다.

## 동작과 접근성

- PC·태블릿 드롭다운은 버튼 재클릭, 바깥 클릭, `Escape` 키로 닫힌다.
- `Escape`로 닫으면 포커스를 언어 버튼으로 되돌린다.
- 현재 언어에는 `aria-current="page"`를 유지한다.
- 수정 키 클릭과 보조 클릭은 새 탭 동작을 보존한다.
- 언어 전환 시 현재 위치가 승인된 홈페이지 해시라면 그대로 유지한다.
- 모바일 언어 링크도 같은 URL 생성 로직을 재사용한다.

## 구현 경계

- `components/home/language-selector.tsx`의 기존 상태·접근성·URL 동작은 유지하고, 표시 구조에 필요한 최소한의 클래스만 조정한다.
- `components/home/site-header.tsx`의 모바일 언어 영역은 기존 링크 데이터를 유지하면서 한 열 목록으로 바꾼다.
- `app/globals.css`에서 PC 드롭다운과 모바일 목록의 레이아웃·상태 스타일을 통일한다.
- 번역 데이터, 지점 정보, 예약·지도·전화 링크는 변경하지 않는다.

## 검증

- 먼저 세로 목록, 언어 순서, 현재 언어 상태를 요구하는 자동 테스트를 추가하고 실패를 확인한다.
- 최소 CSS·컴포넌트 변경 후 해당 테스트와 전체 테스트를 통과시킨다.
- 린트와 프로덕션 빌드를 실행한다.
- PC, 태블릿, 모바일 화면에서 메뉴가 한 열로 표시되고 잘림·가로 넘침·고정 예약 바 겹침이 없는지 확인한다.
- 바깥 클릭, `Escape`, 현재 해시 보존, 네 언어 경로 이동을 실제 브라우저에서 확인한다.
- GitHub `main`에 푸시한 뒤 기존 Vercel 프로젝트 `my-shop-39ab`의 자동 배포와 연결 도메인을 확인한다. 새 Vercel 프로젝트나 수동 배포는 만들지 않는다.

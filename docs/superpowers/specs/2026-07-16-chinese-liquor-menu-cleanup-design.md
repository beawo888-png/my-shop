# 중국주류 맥주 사진 교체 및 메뉴 정리 설계

## 목표

중국주류 메뉴의 칭다오 맥주와 하얼빈 맥주 사진을 사용자가 제공한 제품 사진으로 교체한다. 타이거 맥주, 이과두주, 컵술 고량주는 상품명, 가격, 설명, 메뉴 카드가 나타나지 않도록 메뉴 데이터에서 삭제한다.

## 변경 범위

- `칭다오 맥주 640ml 4.7도`의 기존 공용 이미지를 제공받은 `칭도우.jpg`로 교체한다.
- `하얼빈 맥주 500ml 4.3도`의 기존 공용 이미지를 제공받은 `하얼빈.jpg`로 교체한다.
- 두 이미지는 `public/images/wangjing/menu/` 아래에 제품을 식별할 수 있는 영문 파일명으로 저장한다.
- 두 맥주 카드의 상품명, 가격, 설명, 순서는 유지한다.
- `타이거 맥주 640ml 5도`, `이과두주 125ml 56도`, `컵술 고량주 100ml 38도` 항목을 `lib/menu-content.ts`에서 완전히 삭제한다.
- 삭제된 이과두주와 컵술의 전용 이미지 파일도 삭제한다.
- 타이거 맥주가 사용하던 `beer-cheers-table.jpg`는 다른 메뉴나 대체 이미지에서 사용할 수 있으므로 이번 변경에서 삭제하지 않는다.
- 다른 메뉴 항목과 공용 이미지에는 변경을 가하지 않는다.

## 이미지 표시

칭다오와 하얼빈 이미지는 기존 메뉴 카드의 `contain` 맞춤 방식을 유지해 병 전체와 라벨이 잘리지 않도록 표시한다. 이미지 로드 실패 시 기존 공통 대체 이미지 동작을 그대로 사용한다.

## 검증

- 메뉴 데이터에서 삭제 대상 3개의 상품명, 가격, 설명 및 이미지 참조가 사라졌는지 검사한다.
- 칭다오와 하얼빈이 각각 제공받은 새 로컬 이미지 파일을 `contain` 방식으로 참조하는지 검사한다.
- 새 이미지 파일이 실제로 존재하고 비어 있지 않은지 검사한다.
- 이과두주와 컵술의 전용 이미지 파일이 제거됐는지 검사한다.
- 전체 테스트, 린트, 프로덕션 빌드를 실행해 다른 화면에 회귀가 없는지 확인한다.

## Pencil 적용 여부

기존 카드의 구조, 배치, 스타일 또는 상호작용을 바꾸지 않고 데이터와 이미지 자산만 교체하므로 Pencil 스케치는 변경하지 않는다.

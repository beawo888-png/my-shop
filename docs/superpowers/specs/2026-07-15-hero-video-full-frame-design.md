# 상단 영상 전체 노출 디자인

## 목표

현재 상단 홍보 영상의 확대 크롭을 없애 양다리 전체가 구워지는 장면을 잘리지 않게 보여준다. 기존 상단 영역의 높이, 문구, 버튼, 어두운 가독성 필터와 왕징 색상은 유지한다.

## 승인된 구도

- 중앙의 실제 홍보 영상은 `contain` 방식으로 표시해 모든 프레임을 온전히 노출한다.
- 영상 비율과 상단 영역 비율이 달라 생기는 공간은 기존 대표 이미지를 확대한 흐린 배경으로 채운다.
- 흐린 배경은 같은 MP4를 한 번 더 재생하지 않고 기존 포스터 이미지를 사용한다.
- 데스크톱과 모바일 모두 영상 초점을 중앙에 고정한다.
- 영상 재생 방식은 음소거 자동 재생, 무한 반복, 모바일 인라인 재생을 유지한다.

## 화면 계층

1. 가장 뒤에는 기존 `hero__poster` 이미지를 화면에 꽉 채운다.
2. 포스터에는 확대와 블러를 적용해 빈 여백처럼 보이지 않는 분위기 배경을 만든다.
3. 그 위의 `hero__video`는 중앙에서 전체가 보이도록 `object-fit: contain`을 적용한다.
4. 기존 `hero__overlay`, 제목, 설명, 예약 버튼과 신뢰 정보는 그 위에 그대로 유지한다.

## 반응형과 접근성

- 모바일에서도 영상 전체를 중앙에 표시하고 위아래 남는 공간은 흐린 배경으로 채운다.
- 영상은 포인터 입력을 받지 않아 네이버 예약과 단체 모임 버튼을 방해하지 않는다.
- 동작 최소화 설정에서는 영상을 숨기고 포스터를 `contain`으로 전환해 양다리 전체 이미지를 보여준다.
- 흐린 배경은 장식 요소이며 기존 영상의 접근성 속성은 변경하지 않는다.

## 오류 처리와 성능

- 영상 로딩 중에는 `video`의 기존 포스터가 중앙에 전체 형태로 표시된다.
- 영상 재생이 실패해도 뒤쪽 대표 이미지 때문에 빈 화면이 나타나지 않는다.
- 새 영상 파일, 외부 저장소, 자바스크립트 상태나 추가 의존성을 만들지 않는다.
- 한 개의 MP4만 재생하므로 현재와 같은 네트워크 및 디코딩 비용을 유지한다.

## 검증

- 구조 테스트에서 `hero__video`에 `object-fit: contain`이 적용되는지 확인한다.
- 포스터 배경에 블러와 확대가 적용되는지 확인한다.
- 모바일 중앙 정렬과 동작 최소화 환경의 포스터 `contain` 전환을 확인한다.
- 전체 테스트, ESLint와 프로덕션 빌드를 실행한다.
- 배포 후 공식 도메인의 Hero CSS와 MP4 응답을 확인한다.

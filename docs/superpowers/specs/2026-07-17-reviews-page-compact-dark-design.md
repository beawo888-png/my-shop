# 고객리뷰 페이지 로고 및 첫 화면 배치 개선 설계

## 목표

- 홈 화면 상단 로고의 크기와 스타일은 변경하지 않는다.
- 고객리뷰 페이지도 홈페이지와 동일한 공통 상단바를 사용한다.
- 브랜드 로고, 대표메뉴, 왕징이야기, 단체모임, 고객리뷰, 지점안내, 네이버 예약을 포함한 상단바 전체를 스크롤 중에도 화면 상단에 고정한다.
- 데스크톱에서 고객리뷰 페이지를 열었을 때 모란본점과 판교점의 리뷰 버튼까지 첫 화면 안에 모두 보이게 한다.
- 제목 영역의 짙은 갈색 배경을 카드 영역과 페이지 하단까지 끊김 없이 이어간다.

## 선택한 방향

고객리뷰 페이지의 축약 헤더를 제거하고 홈페이지에서 사용하는 `SiteHeader`를 그대로 연결한다. 밝은 카드와 붉은 리뷰 버튼은 유지하고, 페이지 전체 배경을 기존 제목 영역의 짙은 갈색 계열로 통일한다. 제목 영역의 상하 여백, 콘텐츠 여백, 카드의 최소 높이와 내부 여백을 함께 줄여 두 카드의 버튼까지 데스크톱 첫 화면에 들어오게 한다.

검토한 다른 방법은 카드까지 모두 어둡게 바꾸는 방식과 제목 영역만 줄이고 콘텐츠 배경은 밝게 유지하는 방식이다. 전자는 지점명과 버튼의 대비가 약해지고, 후자는 사용자가 요청한 하단까지 이어지는 배경을 충족하지 않아 선택하지 않았다.

## 변경 범위

### 고정 헤더

- 고객리뷰 페이지의 별도 `reviews-page__header`를 제거한다.
- 홈페이지와 동일한 `SiteHeader`를 `sectionRoot="/"`로 렌더링해 홈 섹션 이동과 네이버 예약 메뉴를 그대로 제공한다.
- 공통 `site-header`의 기존 고정 위치, 로고, 내비게이션, 예약 드롭다운, 모바일 메뉴 동작을 재사용한다.

### 레이아웃

- `reviews-page`의 기본 배경을 짙은 갈색으로 변경한다.
- 제목 영역과 콘텐츠 영역 사이에 색상 단절이 생기지 않게 한다.
- 데스크톱 제목 영역과 콘텐츠 영역의 세로 여백을 축소한다.
- 두 카드의 최소 높이와 내부 여백, 주소 아래 여백을 축소하되 버튼의 클릭 영역과 가독성은 유지한다.
- 기존 데스크톱 2열, 모바일 1열 구조는 유지한다.

### 반응형 동작

- 데스크톱은 두 지점 카드와 버튼이 첫 화면 안에 보이는 것을 우선한다.
- 모바일은 한 열 구조라 스크롤을 허용하며, 로고가 헤더 폭을 넘지 않고 카드 내용이 잘리지 않는 것을 우선한다.

## 검증

- 정적 테스트로 고객리뷰 페이지의 공통 `SiteHeader` 사용, 전체 헤더의 고정 위치, 전체 어두운 배경, 축소된 카드 높이 규칙을 확인한다.
- 기존 전체 테스트와 린트를 실행해 홈 화면 로고 및 다른 페이지에 회귀가 없는지 확인한다.
- 개발 서버에서 고객리뷰 페이지를 1440 × 900으로 캡처하여 로고, 배경 연결, 두 리뷰 버튼의 첫 화면 노출을 시각적으로 확인한다.
- 페이지를 스크롤한 상태에서도 로고와 `홈으로` 링크를 포함한 전체 헤더가 화면 상단에 유지되는지 확인한다.
- 모바일 폭에서도 로고 넘침, 카드 잘림, 버튼 가독성을 확인한다.

## 범위 제외

- 홈 화면 헤더와 로고 디자인 변경
- 리뷰 링크 또는 지점 데이터 변경
- 고객리뷰 카드의 문구와 기능 변경

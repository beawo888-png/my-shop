# 홈 SEO·GEO 콘텐츠 디자인

## 목표

첨부된 브랜드·맛·지점 이미지를 검색엔진과 AI 검색이 읽을 수 있는 실제 HTML 콘텐츠로 재구성한다. 기존 왕징의 진한 갈색, 크림, 금색, 적색 팔레트와 데스크톱·모바일 흐름을 유지한다.

## 콘텐츠 구조

1. 왕징 이야기
   - 600일의 연구로 완성한 양다리의 맛
   - 48시간 저온 숙성
   - 400°C 고온 숯불 초벌
   - 시그니처 숙성 소스
   - 대표 메뉴: 통양다리구이, 양꼬치, 프리미엄 양갈비, 꿔바로우
2. 지점과 모임
   - 판교점: 판교역·라스트리트, 회식·비즈니스 미팅·가족모임
   - 모란본점: 모란역, 단체모임·가족외식·청첩장모임
   - 각 지점 카드 상단에 실제 매장 사진을 바탕으로 만든 단체석 합성 이미지를 크게 노출
   - 각 지점의 메뉴, 주차, 예약 및 지도 링크
3. 구조화 데이터
   - 모란본점과 판교점을 각각 `Restaurant`로 정의
   - 주소, 전화, 이미지, 메뉴, 예약, 지도 정보를 실제 화면과 일치시킴

## 시각 방향

- 브랜드/맛 섹션: `--ink` 배경, 금색 제목, 크림색 본문, 적색은 작은 강조에만 사용
- 지점/모임 섹션: `--cream` 배경, `--paper` 카드, 금색·적색 레이블
- 첨부된 `ChatGPT Image 2026년 7월 18일 오후 01_50_00.png`의 전체 정보 구조와 밀도를 실제 HTML/CSS로 재구성한다. 참고 이미지를 통째로 배경 이미지로 사용하지 않는다.
- 섹션 상단은 `DINING & LOCATION`, 2줄 제목, 소개 문단, 모임 유형 6개를 순서대로 배치한다.
- 모임 유형은 단체회식, 가족외식, 청첩장모임, 비즈니스 미팅, 친구모임, 데이트·기념일이며 데스크톱에서는 한 줄, 모바일에서는 2열 또는 1열로 재배치한다.
- 데스크톱 지점 영역은 모란본점과 판교점 상세 카드를 2열로 배치한다. 각 카드 상단은 지점명·접근성 문구와 합성 이미지가 나란히 보이고, 하단에는 오시는 길, 추천 모임, 대표 메뉴, 주차 안내, 예약·길찾기 버튼을 둔다.
- 지점 카드 사진은 16:9 비율의 대형 배너가 아니라 참고 이미지처럼 카드 상단 우측의 가로형 사진 영역으로 사용한다. 모란본점은 모란 합성 이미지, 판교점은 판교 합성 이미지를 사용한다.
- 두 지점 카드 아래에는 동일한 숙성·숯불 원칙을 알리는 중앙 안내 띠를 배치한다.
- 그 아래에는 `모란본점은 이런 분께 추천합니다`, `판교점은 이런 분께 추천합니다` 카드 2개를 배치하고, 각 카드에 해당 합성 이미지의 작은 크롭과 지점별 추천 문구를 넣는다.
- 섹션 마지막에는 `48시간 숙성`, `400℃ 숯불`, `60분 정성 구이`, `모든 모임을 위한 공간` 네 가지 특징을 한 줄 요약 띠로 제공한다.
- 사진 아래 정보는 오시는 길, 추천 모임, 대표 메뉴, 주차 안내 순서로 제공하고 예약과 지도 버튼을 카드 하단에 고정한다.
- 모바일은 제목, 모임 유형, 모란 카드, 판교 카드, 중앙 안내, 추천 카드, 네 가지 특징 순서로 자연스럽게 세로 배치하며 글자나 버튼이 잘리지 않게 한다.

## 반응형·검증

- 데스크톱은 두 지점을 한 화면에서 비교할 수 있도록 2열을 유지한다.
- 모바일은 카드 1열, 버튼 2열을 기본으로 하며 좁은 화면에서는 버튼을 1열로 전환한다.
- 이미지 파일 존재, 지점별 대체 텍스트, 예약·지도 링크, 모바일 1열 전환을 자동 테스트한다.

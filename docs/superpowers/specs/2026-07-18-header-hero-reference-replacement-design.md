# 헤더·히어로 참고 이미지 반영 디자인

## 목표

첨부된 참고 이미지와 동일한 인상과 정보 구조가 되도록 홈페이지 상단 헤더와 첫 화면 히어로를 조정한다. 기존 로고, 양고기 영상, 예약 링크와 내비게이션 기능은 재사용한다.

## 적용 범위

- 홈페이지 상단 헤더와 히어로 영역만 변경한다.
- 기존 브랜드 로고와 양고기 홍보 영상 및 포스터 이미지를 유지한다.
- 헤더의 내비게이션, 예약 지점 선택 드롭다운, 모바일 햄버거 메뉴 기능을 유지한다.
- 히어로의 문구, 버튼, 여백, 글자 크기, 색상, 배경 오버레이를 참고 이미지에 맞춘다.
- 현재 히어로 하단의 매장 주요 정보 바는 히어로에서 제거한다.
- 홈페이지 아래쪽 콘텐츠와 다른 페이지는 변경하지 않는다.

## 데스크톱 화면

### 헤더

- 검정에 가까운 짙은 갈색 배경을 사용한다.
- 왼쪽에는 현재 브랜드 로고를 배치한다.
- 중앙에는 `대표 메뉴`, `브랜드 스토리`, `단체 모임`, `고객 리뷰`, `지점 안내` 순서로 메뉴를 배치한다.
- 오른쪽에는 빨간색 `네이버 예약` 버튼과 아래 방향 아이콘을 배치한다.
- 예약 버튼을 누르면 현재와 같이 모란본점과 판교점 예약 링크를 선택할 수 있다.

### 히어로

- 기존 양고기 홍보 영상을 화면 너비 전체에 채운다.
- 영상 위에는 왼쪽이 진하고 오른쪽으로 갈수록 옅어지는 어두운 오버레이를 적용하여 글자의 명암 대비를 확보한다.
- 왼쪽 콘텐츠는 다음 순서로 배치한다.
  1. `PANGYO · CHINESE LAMB DINING`
  2. `불향으로 완성한 양고기,` / `중요한 자리를 위한 왕징`
  3. `판교역 가까이에서 만나는 품격 있는 중국 양고기 요리.` / `회식부터 가족 모임까지 편안하게 준비해 드립니다.`
  4. 빨간색 `네이버 예약` 버튼과 테두리형 `단체 모임 안내` 버튼
- 첫 화면 높이 안에서 참고 이미지와 유사한 비율과 간격을 유지한다.

## 모바일 화면

- 기존 모바일 헤더 구조를 유지해 로고와 햄버거 버튼을 표시한다.
- 내비게이션과 지점별 예약 링크는 햄버거 메뉴 안에서 사용할 수 있어야 한다.
- 영상은 영역을 가득 채우되 제목과 주요 음식 장면이 함께 보이도록 위치를 조정한다.
- 제목, 본문, 버튼 크기와 여백을 화면 폭에 맞게 줄인다.
- 두 버튼은 430px 이하 화면에서 세로로 배치한다.

## 구현 경계

- `SiteHeader`와 `HeroSection`의 기존 역할과 인터페이스는 유지한다.
- 반복 사용되는 메뉴와 예약 지점 데이터는 `site-content.ts`를 계속 사용한다.
- 디자인 변경은 기존 CSS 클래스 체계 안에서 필요한 범위만 수정한다.
- 작업 트리에 존재하는 다른 미완료 변경은 덮어쓰거나 되돌리지 않는다.
- 앱 코드를 수정하기 전에 `초안` Pencil 파일에 승인된 상단 화면 구성을 먼저 반영한다.

## 접근성과 동작

- 배경 영상은 음소거, 자동 재생, 반복 재생, 인라인 재생을 유지한다.
- 포스터 이미지를 유지해 영상 로딩 전에도 화면이 비어 보이지 않게 한다.
- 모든 내비게이션과 버튼은 키보드로 사용할 수 있어야 한다.
- 예약 드롭다운의 바깥 클릭 및 Escape 닫기 동작을 유지한다.
- 텍스트와 배경 간 명암 대비를 충분히 확보한다.

## 검증

- 헤더 메뉴 순서와 히어로 문구가 참고 이미지와 일치하는지 자동 테스트로 확인한다.
- 기존 예약 드롭다운, 모바일 메뉴 및 링크 동작 관련 테스트를 유지한다.
- 프로젝트의 전체 테스트와 린트를 실행한다.
- 데스크톱과 모바일 화면을 각각 렌더링해 참고 이미지와 시각적으로 비교한다.
- 기존 홈페이지 하단 콘텐츠 및 메뉴·리뷰 페이지에 회귀가 없는지 확인한다.

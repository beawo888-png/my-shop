# 홈 상단 로고 크기 조정 디자인

## 목표

홈 화면 상단바의 왕징 로고를 현재보다 또렷하고 크게 보이도록 조정한다.

## 적용 범위

- 홈 화면 상단바 로고에만 적용한다.
- PC 로고 너비는 최대 `250px`로 확대한다.
- 모바일 로고 너비는 `170px`로 확대한다.
- 태블릿 구간은 메뉴 공간을 보호하기 위해 PC와 모바일 사이 크기로 자연스럽게 축소한다.
- 상단바 높이, 메뉴 위치, 네이버 예약 버튼, 고정 동작은 변경하지 않는다.
- 메뉴·고객리뷰 등 다른 페이지의 공용 상단바 로고 크기는 변경하지 않는다.

## 검증

- 홈 헤더에만 전용 클래스가 적용되는지 확인한다.
- PC와 모바일 로고 너비 규칙을 자동 테스트한다.
- 1440px와 390px 미리보기에서 메뉴 겹침과 가로 넘침이 없는지 확인한다.

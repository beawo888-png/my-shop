# 상단 영상 이전 구도 복원 디자인

## 목표

양다리 전체 노출을 위해 적용했던 중앙 축소 영상과 흐린 배경을 제거하고, 사용자 선호가 더 높았던 바로 전 배포의 꽉 찬 영상 구도로 복원한다.

## 복원 범위

- `HeroSection`의 영상 파일, 포스터, 문구, 버튼과 신뢰 정보는 변경하지 않는다.
- `hero__poster`와 `hero__video`가 상단 영역 전체를 `cover` 방식으로 채운다.
- 데스크톱 포스터 초점은 `center 48%`, 영상 초점은 `center`로 복원한다.
- 모바일의 포스터와 영상 초점은 `58% center`로 복원한다.
- 포스터 블러, 확대 변형과 영상 뒤 반투명 배경을 제거한다.
- 음소거 자동 재생, 무한 반복과 모바일 인라인 재생은 유지한다.

## 접근성과 오류 처리

- 동작 최소화 설정에서는 영상을 숨기고 기존 포스터를 표시한다.
- 영상 로딩이나 재생이 실패하면 기존 포스터가 상단 영역을 채운다.
- 영상과 포스터는 포인터 입력을 받지 않아 예약 버튼을 방해하지 않는다.

## 구현 방식

- 마지막 전체 노출 변경의 CSS 값만 이전 커밋 `0ece698` 상태로 되돌린다.
- 컴포넌트, 영상 자산, 의존성과 다른 홈페이지 섹션은 수정하지 않는다.
- 기존 구조 테스트를 이전 `cover` 구도 계약으로 복원한다.
- 전체 테스트, ESLint와 프로덕션 빌드를 실행한다.
- Vercel은 기존 프로젝트에 `--prod --yes`로 배포한다.

## Pencil 스케치

- `C:\vibecoding\my-shop\초안`의 `desktop-hero`와 `mobile-hero`를 이전 구도로 복원했다.
- 데스크톱은 중앙 채움, 모바일은 `58% center` 초점 조건을 메타데이터에 기록했다.
- 데스크톱과 모바일 모두 Pencil 레이아웃 검사에서 문제가 없음을 확인했다.

# 왕징 메뉴 탐색 화면 재설계

## 목표

왕징양다리양꼬치의 메뉴 화면을 육즙관리소 메뉴 페이지의 정보 구조와 상호작용을 참고해 재구성한다. 홈 화면에서 사용하는 기존 왕징 상단 바를 메뉴 화면에도 그대로 사용하고 화면 상단에 고정한다. 메뉴 화면에서는 지점과 메뉴 분류를 둥근 탭으로 선택하며, 페이지 이동 없이 메뉴가 즉시 바뀌어야 한다.

## 확정된 요구사항

- 메뉴 페이지 상단에는 새 헤더를 만들지 않고 홈 화면의 `SiteHeader`를 그대로 재사용한다.
- 데스크톱의 로고, 중앙 내비게이션, 네이버 예약 버튼과 모바일의 로고, 햄버거 메뉴 구성을 홈 화면과 동일하게 유지한다.
- 상단 바는 스크롤 중에도 화면 위에 고정한다.
- 상단 바 아래에 `전체 메뉴` 제목과 `44개 메뉴 · 모란본점 · 판교점` 안내를 표시한다.
- 첫 번째 탭 행에는 `전체메뉴`, `모란본점`, `판교점`을 표시한다.
- 두 번째 탭 행에는 기존 다섯 개 메뉴 분류를 표시한다.
- 지점 탭과 메뉴 분류 탭은 페이지 이동 없이 즉시 결과를 갱신한다.
- 모란본점과 판교점은 동일한 44개 메뉴 데이터를 공유한다.
- 선택된 탭은 왕징 레드 배경과 밝은 글자로 강조한다.
- 메뉴 카드는 데스크톱 4열, 태블릿 2열, 모바일 1열로 배치한다.

## 화면 구조

### 고정 상단 바

홈 화면의 `SiteHeader` 컴포넌트를 메뉴 화면에서 재사용한다. 메뉴 화면에서는 로고와 내비게이션의 해시 링크가 현재 메뉴 문서가 아니라 홈 화면의 대응 섹션으로 이동하도록 루트 경로가 포함된 링크를 사용한다. 예약 지점 선택, 외부 링크 안전 속성, 모바일 메뉴 동작은 기존 기능을 유지한다.

### 메뉴 소개 영역

상단 바 바로 아래에 여백을 두고 다음 정보를 제공한다.

- 제목: `전체 메뉴`
- 보조 문구: `44개 메뉴 · 모란본점 · 판교점`

홈 화면의 짙은 갈색, 크림색, 왕징 레드 디자인 토큰을 사용하되 육즙관리소처럼 넉넉한 여백과 간결한 정보 계층을 적용한다.

### 지점 및 분류 탭

지점 탭과 메뉴 분류 탭은 서로 독립적인 두 필터다.

- 기본 지점: `전체메뉴`
- 지점 선택지: `전체메뉴`, `모란본점`, `판교점`
- 기본 분류: 모든 분류
- 분류 선택지: 현재 `PANGYO_MENU_GROUPS`에 정의된 다섯 개 분류

탭은 둥근 캡슐 형태이며 선택된 탭은 왕징 레드, 선택되지 않은 탭은 밝은 배경과 얇은 테두리를 사용한다. 작은 화면에서는 탭을 축소하거나 여러 줄로 강제하지 않고 가로 스크롤을 제공한다.

### 메뉴 그리드

기본 `/menu`에서는 44개 메뉴 전체를 표시한다. 분류 탭을 선택하면 해당 분류의 메뉴만 표시한다. 지점별 메뉴가 동일하므로 `전체메뉴`, `모란본점`, `판교점` 모두 같은 메뉴 배열을 사용하며 지점 선택 상태와 화면 안내 문구만 변경한다.

메뉴 카드는 기존 이미지, 이름, 설명, 가격, 대표 표시와 대체 이미지 동작을 유지한다. 그리드는 4열, 2열, 1열 순으로 반응한다.

## 컴포넌트와 데이터 흐름

- `SiteHeader`: 홈과 메뉴 페이지가 공유한다. 페이지 문맥에 따라 홈 섹션 링크의 기준 경로만 조정한다.
- 메뉴 페이지 서버 컴포넌트: 메뉴 데이터와 초기 분류를 준비하고 구조화 데이터를 렌더링한다.
- 메뉴 탐색 클라이언트 컴포넌트: 활성 지점과 활성 분류 상태를 관리하고 표시할 메뉴를 계산한다.
- `PANGYO_MENU_GROUPS`: 모란본점과 판교점이 공유하는 단일 메뉴 데이터 소스로 유지한다. 중복 데이터는 만들지 않는다.

`/menu`는 전체 메뉴를 기본으로 연다. 기존 `/menu/[category]` 경로는 유지하며 해당 분류가 초기 선택된 상태로 같은 메뉴 탐색 화면을 렌더링한다. 탭 클릭은 URL을 바꾸지 않는다.

## 접근성과 예외 처리

- 탭은 실제 `button` 요소를 사용한다.
- 선택 상태는 `aria-pressed` 또는 동등한 접근성 속성으로 전달한다.
- 키보드 포커스가 명확히 보이도록 기존 포커스 스타일을 유지한다.
- 필터 결과가 비어 있으면 `등록된 메뉴가 없습니다` 안내를 표시한다.
- 이미지가 없거나 로딩에 실패하면 기존 분류별 대체 이미지를 사용한다.
- 모바일에서 문서와 카드가 가로로 넘치지 않아야 한다.

## 검증 기준

- 홈과 메뉴 페이지가 같은 상단 바 구조와 브랜드 스타일을 사용한다.
- 메뉴 페이지에서 상단 바가 스크롤 중에도 고정된다.
- 기본 `/menu`에 메뉴 44개가 표시된다.
- 세 지점 탭이 둥근 형태로 표시되고 클릭 즉시 선택 상태가 갱신된다.
- 다섯 분류 탭이 클릭 즉시 해당 메뉴만 표시한다.
- 지점 탭과 분류 탭을 함께 사용할 수 있다.
- 기존 분류 URL은 유효하고 올바른 초기 분류를 연다.
- 데스크톱 4열, 태블릿 2열, 모바일 1열이 유지된다.
- 모바일 탭 행은 가로 스크롤되고 전체 문서는 가로로 넘치지 않는다.
- 테스트, 린트, 프로덕션 빌드, 데스크톱·모바일 실제 브라우저 검증이 통과한다.

## 범위 제외

- 모란본점 전용 메뉴 데이터 추가
- 탭 선택 상태를 쿼리 문자열이나 브라우저 저장소에 보존
- 메뉴 가격 및 사진 자체의 변경
- 홈 화면 상단 바의 디자인 변경

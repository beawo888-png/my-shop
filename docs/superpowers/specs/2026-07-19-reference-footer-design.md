# 육즙관리소 참고 푸터 재구성

## 목표

홈페이지 맨 아래 푸터를 사용자가 제공한 육즙관리소 참고 이미지와 동일한 정보 배열로 재구성한다. 왕징의 기존 짙은 갈색, 크림색, 금색 시각 체계는 유지한다.

## 데스크톱 배열

푸터의 본문은 가로 4열로 구성한다.

1. 브랜드: `왕징양다리양꼬치`, `PREMIUM CHINESE LAMB DINING`, 인스타그램·유튜브·카카오·틱톡 링크
2. MORAN: `왕징양다리양꼬치 모란본점`, 주소, 클릭 가능한 전화번호
3. PANGYO: `왕징양다리양꼬치 판교점`, 주소, 클릭 가능한 전화번호
4. NAV: 대표메뉴, 단체모임, 예약

본문 아래에는 전체 너비의 구분선을 두고, 마지막 줄 왼쪽에 `왕징양다리양꼬치 메뉴/가격은 매장 상황에 따라 다를 수 있습니다.`를, 오른쪽에 `@wangjingyangdali_official`을 배치한다.

## 링크

- 인스타그램: `https://www.instagram.com/wangjingyangdali_official/`
- 유튜브: `https://www.youtube.com/@wangjing_lamb`
- 카카오: `https://place.map.kakao.com/1387600612`
- 틱톡: `https://www.tiktok.com/@wangjing_lamb`
- 대표메뉴: `/menu`
- 단체모임: `/#group`
- 예약: 홈페이지 예약 영역 `/#reservation`
- 지점 전화번호: 각 지점의 `tel:` 링크

외부 서비스 링크는 새 탭에서 열고, 내부 링크는 현재 탭에서 이동한다. 소셜 링크에는 화면낭독기용 서비스 이름을 제공한다.

## 반응형

- 데스크톱: 참고 이미지와 같은 4열
- 태블릿: 2열
- 모바일: 1열 세로 배열
- 하단 안내와 계정명은 모바일에서 세로로 쌓는다.

## 검증

- 소스 테스트로 모든 문구와 URL, 4열 구조용 클래스, 전화 링크를 확인한다.
- 기존 푸터 로고 테스트는 새 텍스트 브랜드 구조에 맞게 갱신한다.
- 전체 테스트와 린트를 실행한다.
- 로컬 페이지를 데스크톱과 모바일 크기로 열어 푸터 배열과 링크 상태를 시각 검증한다.

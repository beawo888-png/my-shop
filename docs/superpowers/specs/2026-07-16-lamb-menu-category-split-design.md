# 양고기 메뉴 카테고리 분리 설계

## 목표

현재 하나의 양고기·꼬치 카테고리에 들어 있는 메뉴를 `시그니처 양다리`와 `양꼬치 &세트메뉴` 두 카테고리로 분리한다. 전체 메뉴 수와 기존 메뉴의 이미지, 설명, 표시 순서는 유지한다.

## 메뉴 구성

### 시그니처 양다리

- `400도 숯불로 완성한 겉바속촉 양다리구이 (대)` — `90,000원`
- `400도 숯불로 완성한 겉바속촉 양다리구이 (중)` — `80,000원`

두 메뉴는 현재 양다리 메뉴가 사용하는 이미지와 설명을 각각 그대로 유지한다.

### 양꼬치 &세트메뉴

현재 첫 번째 카테고리에서 양다리 두 메뉴를 제외한 모든 메뉴를 기존 순서대로 이동한다.

- 고급양갈비
- 생양꼬치
- 양념양꼬치
- 양갈비살꼬치
- 새우꼬치

각 메뉴의 이름, 가격, 설명, 이미지, 이미지 표시 방식은 변경하지 않는다.

## 구현 방식

`lib/menu-content.ts`의 메뉴 그룹 타입에 새 그룹 식별자를 추가하고, 기존 첫 그룹을 두 개의 독립된 그룹으로 나눈다. 메뉴 페이지는 그룹 배열을 순회해 표시하므로 렌더링 컴포넌트에 조건문이나 별도 필터를 추가하지 않는다.

메뉴 그룹 수는 4개에서 5개로 증가하지만 전체 메뉴 수는 44개로 유지한다. 구조화 데이터는 동일한 메뉴 그룹 데이터를 사용하므로 새 분류와 메뉴명이 자동 반영되도록 유지한다.

## 화면 및 스케치

기존 카드, 그리드, 타이포그래피, 반응형 레이아웃은 변경하지 않고 데이터의 카테고리 경계와 문구만 바꾼다. 따라서 별도의 시각 설계가 필요하지 않아 Pencil 스케치는 수정하지 않는다.

## 검증

- `시그니처 양다리`에 정확히 두 메뉴만 포함되는지 확인한다.
- 두 양다리 메뉴의 새 이름과 가격을 확인한다.
- 나머지 다섯 메뉴가 `양꼬치 &세트메뉴`에 기존 순서로 포함되는지 확인한다.
- 메뉴 그룹 수가 5개이고 전체 메뉴 수가 44개인지 확인한다.
- 기존 전체 테스트와 린트를 실행해 회귀가 없는지 확인한다.

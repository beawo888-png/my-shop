# 홈페이지 탭 순서 및 FAQ 섹션 설계

## 목표

홈페이지 상단 내비게이션의 탭을 사용자가 요청한 순서로 재배치하고, 기존 고객 리뷰 탭 대신 홈페이지 안에서 바로 확인할 수 있는 `자주 묻는 질문` 섹션을 추가한다. 기존 왕징 홈페이지의 크림·먹색·적색 시각 체계와 고객 리뷰 본문은 유지한다.

## 상단 내비게이션

데스크톱과 모바일 내비게이션 모두 다음 순서를 사용한다.

1. 브랜드 스토리
2. 대표 메뉴
3. 지점 안내
4. 단체 모임
5. 자주 묻는 질문

각 탭의 연결 대상은 다음과 같다.

- `브랜드 스토리`: `#story`
- `대표 메뉴`: `/menu` — 기존과 같이 새 탭에서 연다.
- `지점 안내`: `#location`
- `단체 모임`: `#group`
- `자주 묻는 질문`: `#faq`

기존 `고객 리뷰` 탭은 상단 내비게이션에서 제외한다. 홈페이지의 고객 리뷰 섹션과 `/reviews` 페이지는 삭제하거나 변경하지 않는다.

## FAQ 콘텐츠

FAQ 섹션의 영문 레이블은 `FAQ`, 제목은 `자주 묻는 질문`으로 표시한다. 질문은 아래 순서를 유지한다.

### 양고기 특유의 잡내가 걱정돼요.

왕징의 양고기는 15가지 향신 재료를 24시간 우려낸 비법으로 48시간 저온 숙성합니다. 잡내는 줄이고 풍미와 육즙은 살려, 양고기를 처음 드시는 분도 편하게 즐기실 수 있습니다. 처음이시라면 달콤 짭조름한 양념양꼬치부터 시작해 보세요.

### 통양다리구이는 어떻게 주문하나요?

통양다리구이는 **대 1,700g(3~4인, 90,000원)**과 **중 1,500g(2~3인, 80,000원)** 두 가지 크기로 준비됩니다. 400℃ 숯불에서 60분 동안 굽는 메뉴라서 방문 전에 네이버 예약이나 전화로 미리 말씀해 주시면 더 여유롭게 즐기실 수 있습니다.

### 단체 회식이나 청첩장 모임도 가능한가요?

네, 가능합니다. 단체석은 **모란본점 최대 46명**, **판교점 최대 70명**까지 이용하실 수 있습니다. 모란본점은 회식·가족외식·청첩장 모임에, 판교점은 회식·비즈니스 미팅에 특히 많이 찾아주십니다. 인원과 좌석 배치는 지점으로 전화 주시면 맞춰 준비해 드립니다.

### 주차는 어떻게 하나요?

모란본점은 가게 앞 무료주차 4대와 모란공영주차장을 이용하실 수 있습니다. 판교점은 라스트리트 주차장 3시간 무료이며, 인근 공영주차장도 이용 가능합니다.

### 예약은 꼭 해야 하나요?

워크인 방문도 가능하지만, 저녁 시간과 주말에는 대기가 생길 수 있습니다. 네이버 예약으로 원하는 시간과 인원을 미리 알려주시면 편하게 모시겠습니다.

### 양고기 말고 다른 메뉴도 있나요?

꿔바로우, 마라샹궈, 소룽샤, 향라대하 등 정통 중국요리와 볶음밥·면·만두, 그리고 연태구냥·공부가주 같은 중국 백주와 맥주도 다양하게 준비되어 있습니다. 양고기와 곁들이기 좋은 메뉴를 취향에 맞게 선택하실 수 있습니다.

## 구성과 데이터 경계

- `lib/site-content.ts`의 `NAV_ITEMS`가 변경된 탭 순서와 `#faq` 링크를 관리한다.
- FAQ 문답은 별도 데이터 배열로 관리해 콘텐츠와 렌더링 구조를 분리한다.
- 새 FAQ 컴포넌트는 문답 배열을 받아 홈페이지 섹션과 아코디언 항목을 렌더링한다.
- `app/page.tsx`는 기존 고객 리뷰 섹션을 유지하면서 FAQ 섹션을 예약 배너 앞에 추가한다.
- 헤더는 기존처럼 같은 `NAV_ITEMS`를 데스크톱과 모바일에서 함께 사용하므로 두 메뉴의 순서가 항상 일치한다.

## 동작과 접근성

- FAQ 항목은 질문 버튼을 누르면 해당 답변이 펼쳐지거나 접힌다.
- 여러 답변을 동시에 열 수 있다.
- 초기 상태에서는 모든 답변이 접혀 있다.
- 질문은 실제 `button` 요소를 사용하며 최소 48px 이상의 터치 영역을 제공한다.
- 각 버튼은 `aria-expanded`와 `aria-controls`를 제공하고, 답변 영역은 대응하는 고유 ID와 연결한다.
- 키보드의 Tab으로 질문에 이동하고 Enter 또는 Space로 답변을 열고 닫을 수 있다.
- 장식용 열림 표시 아이콘은 스크린 리더에서 숨긴다.
- `#faq` 이동 시 고정 헤더에 제목이 가려지지 않도록 기존 스크롤 여백 규칙을 적용한다.

## 시각 디자인과 반응형

- FAQ 섹션은 기존 `--cream` 또는 `--paper` 기반의 밝은 배경을 사용한다.
- 섹션 제목은 기존 명조 계열 제목 스타일을 재사용한다.
- 질문 행은 먹색 본문, 적색 포인트, 가는 구분선으로 구성한다.
- 답변은 질문보다 작은 본문 크기와 충분한 행간을 사용한다.
- 데스크톱에서는 읽기 편한 최대 너비 안에 목록을 배치하고, 모바일에서는 화면 폭에 맞춰 한 열로 표시한다.
- 긴 가격·인원 문구가 잘리지 않도록 줄바꿈을 허용하고 가로 스크롤이 생기지 않게 한다.

## 오류 및 변경 안전성

- FAQ 데이터가 늘어나도 각 항목의 ID가 겹치지 않도록 안정적인 ID 값을 데이터에 둔다.
- JavaScript가 실행되기 전에도 질문 제목은 HTML에 포함되어 검색 엔진과 보조 기술이 콘텐츠 구조를 인식할 수 있어야 한다.
- 기존 메뉴 페이지, 지점 안내, 단체 모임, 고객 리뷰 링크와 콘텐츠는 이번 변경 범위 밖이며 그대로 유지한다.

## 테스트 및 완료 기준

- 콘텐츠 테스트에서 내비게이션의 정확한 5개 항목과 순서를 확인한다.
- 콘텐츠 테스트에서 FAQ 6개 질문과 핵심 답변 문구를 확인한다.
- 구조 테스트에서 홈페이지가 FAQ 섹션을 렌더링하고 `id="faq"`를 제공하는지 확인한다.
- 컴포넌트 테스트 또는 정적 구조 테스트에서 질문 버튼, `aria-expanded`, `aria-controls` 계약을 확인한다.
- 기존 전체 테스트, ESLint, Next.js 프로덕션 빌드를 실행한다.
- 데스크톱과 모바일에서 탭 순서, FAQ 이동, 펼침·접힘, 긴 문구 줄바꿈, 기존 색상 유지 여부를 시각적으로 확인한다.
- 구현 완료 후 사용자가 기존 배포 흐름을 요청한 경우에만 GitHub와 Vercel 배포를 진행한다.
